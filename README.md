# BBDESIGN

검정 배경과 흰 로고에 버터색·소라색·크림색 폴더를 배치한 반응형 포트폴리오입니다. 메인에서는 화면 좌우 끝까지 이어진 INFO·CONTACT·PORTFOLIO 폴더와 최근 등록 작업 미리보기(기본 6개, 관리자에서 1~12개 조절)를 보여줍니다. 별도의 상단 메뉴 없이 폴더 자체가 내비게이션입니다. 폴더를 누르면 부드럽게 펼쳐져 선택한 페이지만 전체 화면을 차지합니다. 제목 옆 × 또는 Escape로 메인으로 돌아갑니다. 브라우저 뒤로가기도 지원하며, 움직임 줄이기 설정에서는 전환 애니메이션을 생략합니다. INFO는 소개와 공지, CONTACT는 문의 이메일, PORTFOLIO는 카테고리별 작업을 보여줍니다. 모바일에서도 두 열 갤러리를 유지합니다. 공개 화면의 로고와 폴더 대제목은 사용자가 제공한 Dotted Songti Diamond Regular에 CSS 굵기 700을 적용합니다. ® 마크를 유지하며 본문과 관리자 화면의 기존 서체는 변경하지 않습니다.

폰트는 `public/fonts`에서 직접 제공됩니다. Anton은 SIL Open Font License이며 라이선스는 같은 디렉터리의 `OFL.txt`에 포함되어 있습니다.

## 실행

Node.js 24 이상이 필요합니다. 외부 패키지 설치나 빌드 없이 실행합니다.

```sh
cd /workspace/BBDESIGN
npm start
```

기본 포트는 3000입니다. `PORT`, `HOST`로 변경할 수 있습니다. 개발 중 서버 자동 재시작은 `npm run dev`를 사용합니다.

## 관리자 사용

1. 사이트 하단 **관리자 ↗** 또는 `/admin`으로 이동합니다.
2. 첫 실행 시 생성되는 `.data/initial-admin-password.txt` 파일의 비밀번호로 로그인합니다. 이 파일은 웹에서 접근할 수 없고 Git에도 포함되지 않습니다.
3. **비밀번호** 탭에서 나만의 비밀번호로 변경합니다. 변경하면 초기 비밀번호 파일은 삭제됩니다.
4. **포트폴리오 → 작업 추가**에서 제목, 카테고리, 설명, 이미지를 선택하고 저장합니다. 새 카테고리는 직접 입력하면 생성됩니다.
5. **섹션 구성**에서 세 폴더의 이름(최대 16자), 순서, 공개 여부, 메인 미리보기 수, 예시 디자인 표시 여부를 설정합니다. 최소 한 섹션은 공개해야 합니다.
6. **공지 · 소개**에서 사이트 이름, 소개와 공지를 수정합니다. **연락처**에서는 CONTACT 제목, 안내 문구, 문의 이메일을 수정합니다.
7. 각 화면의 **저장** 버튼을 누르면 공개 사이트를 새로 열었을 때 반영됩니다. 상단 **사이트 보기 ↗**로 새 탭에서 확인합니다. 저장 전에는 변경사항 표시와 페이지 이탈 경고가 나옵니다.

이미지는 JPG, PNG, GIF, WEBP 형식으로 1~10장, 장당 8MB, 업로드 합계 16MB까지 가능합니다. 첫 이미지가 대표 이미지입니다. 수정 화면에서 기존 이미지를 제거하거나 새 이미지를 추가할 수 있습니다. 저장하면 공개 화면에 즉시 반영됩니다.

실제 작업이 없고 예시 표시 설정이 켜져 있을 때만 레이아웃 예시 4개를 보여줍니다. 첫 작업을 등록하면 예시는 숨겨집니다. 현재 소개 문구도 시작용 예시이며 관리자에서 수정할 수 있습니다.

## 보관과 공개 배포

`.data/portfolio.sqlite`에 글과 비밀번호 해시, `.data/uploads/`에 이미지를 보관합니다. `.data` 전체가 지속적으로 보존되는 Node.js 서버가 필요합니다. 서버 종료 후 `.data` 전체를 함께 백업하세요. 파일이 사라지는 임시 호스팅이나 정적 파일 호스팅만으로는 업로드 기능이 작동하지 않습니다.

- `DATA_DIR`: 데이터 디렉터리 변경(기본 `.data`).
- `ADMIN_PASSWORD`: 최초 데이터베이스 생성 시에만 사용할 관리자 비밀번호. 12자 이상을 보안 환경변수로 지정할 수 있습니다. 기존 비밀번호는 덮어쓰지 않습니다.
- `COOKIE_SECURE=true`: HTTPS로 공개 배포할 때 설정합니다. HTTPS 리버스 프록시는 원래 Host와 Origin을 보존해야 합니다.
- 관리자 로그인은 8시간 유지되며 서버 재시작 시 다시 로그인합니다.

현재 작업은 개발 환경에 구현되어 있으며 공개 도메인 배포는 별도입니다. 단일 서버용 SQLite 구성입니다.

## 검증

```sh
npm run check
npm test
```

다운로드한 HTML은 화면 확인용이며 관리자 저장 기능은 Node 서버에서 실행되는 `/admin`에서 사용합니다.

통합 테스트는 별도의 임시 데이터베이스로 섹션 설정의 인증·검증·보존, 소개/연락처 부분 수정 시 기존 내용 보존, 인증, 잘못된 업로드 거부, 작업 등록·수정·삭제, 공지 저장, 재시작 후 데이터 유지, 비밀번호 변경, 비공개 파일 접근 차단을 검증합니다.
